# Face-ID: analysis code and aggregate results

Code, run logs, aggregate results and figure source data for the paper

> Hiroshi Higashi. The shape of individual differences in judgment: shared axes, personal weights, and when their spread crosses the consensus. (2026).

Archived version of this repository (Zenodo): https://doi.org/10.5281/zenodo.24302873. The link to the preprint will be added here when it is available.

Face-ID is a two-factor model that reconstructs a person's judgment space (face impressions, aesthetic ratings, similarity judgments) from a
small number of that person's judgments: a shared stimulus embedding plus a low-dimensional latent variable per person, inferred by an
amortised encoder. The models differ in what the latent variable may change: D0 (nothing; population model), D1 (reweighting of the shared
dimensions), D2 (a linear transform), D3 (stimulus-specific offsets in addition).

This repository does **not** contain participant-level data, per-participant model outputs, latent representations, stimulus embeddings or
trained models (see `DATA_LICENSES.md`; the one exception is the source data of the panel `london_z_prefmale.pdf`, one derived index per rater of the
CC BY London Set, without identifiers). Results obtained with the password-protected XPASS-Vis dataset are reported in the paper only: the scripts are
here (74–78), their outputs and logs are not. It contains everything needed to (i) redraw the figures and rebuild the table of all quoted numbers
from aggregate values, and (ii) rerun the whole analysis after obtaining the datasets from their original sources.

## Contents

| Path | Content |
|---|---|
| `src/face_id/` | model, training, inference and plotting code |
| `scripts/` | numbered scripts: data preparation, cross-validation runs, analyses, figures (each script's docstring gives its purpose and the command) |
| `results/*.csv` | aggregate results: per-dataset summaries (`<dataset>_summary.csv`), paired contrasts (`<dataset>_paired.csv`), cross-dataset tables |
| `results/stats_table.csv`, `results/stats_correlations.csv` | test statistics of every contrast quoted in the paper (n, mean difference, s.e.m., 95% CI, t, df, Cohen's d_z, P values) |
| `results/paper_numbers.md` | every number quoted in the paper, generated by `scripts/73_build_paper_numbers.py` |
| `results/figdata/` | source data of the figures: the plotted values of each panel (`<panel>.csv`) |
| `results/paper_numbers_agg.json` | aggregate values of the analyses that need participant-level files (used by `scripts/73` in this repository) |
| `figures/` | the figure panels (one PDF per panel) and `INDEX.md` (what each panel shows) |
| `logs/` | standard output of the training, evaluation and analysis jobs |

## Setup

Python 3.12 and [uv](https://docs.astral.sh/uv/):

```
uv sync
```

`pyproject.toml` takes PyTorch from the CUDA 12.8 wheel index. On a machine without a GPU, replace the `pytorch-cu128` index with the CPU
index; redrawing the figures and rebuilding the tables (stage 1 below) does not use PyTorch at run time. Figures need a LaTeX installation
with Helvetica (`text.usetex`). Packages needed by single scripts only are given in their `Run:` line, e.g.
`uv run --with open_clip_torch --with timm python -I scripts/52_lapis_embed.py`.

## Reproduction

**Stage 1: figures and numbers from the aggregate values (minutes, no data needed).**

```
export FIGDATA=read
uv run --with tabulate python -I scripts/73_build_paper_numbers.py     # results/paper_numbers.md
uv run python -I scripts/13_figures.py                                  # Xu experiments: retest, learning curves, reliability strata, transfer between participants
uv run python -I scripts/34_figures_generalization.py                   # learning curves of the other datasets
uv run python -I scripts/46_figures_summary.py                          # method comparison (Xu), cross-dataset gain and structure
uv run python -I scripts/57_figures_sign_check.py                       # sign check
uv run python -I scripts/72_effect_size_analyze.py                      # effect-size views
uv run python -I scripts/79_var_axis_content.py                         # variation-axis histograms
uv run python -I scripts/88_figure_london_z_prefmale.py                 # London Set: preference for male faces predicted from z
```

With `FIGDATA=read` every panel is drawn from `results/figdata/<panel>.csv` (or from the aggregate table named in the script), and
`scripts/73` takes the values of its participant-level blocks from `results/paper_numbers_agg.json`. The outputs are identical to the files
in this repository.

**Stage 2: analyses from the evaluation files** (`scripts/07`, `25`, `33`, `44`, `83`, `89`, `55`, `72`, `76`–`80`, ...). These read the
per-participant evaluation files written by stage 3, so they can be run only after stage 3.

**Stage 3: everything from the raw data (GPU).** Obtain the datasets (below), then run the numbered scripts in order; the cross-validation
jobs are started by the `scripts/*_run_*.sh` files, which also document the settings (folds, seeds, model sizes). All runs used one GPU
with 16 GB of memory; a single training job takes on the order of minutes, and the complete analysis consists of several thousand jobs (one log file each in `logs/`).
This stage has not been re-run from a fresh copy of this repository.
Run without `FIGDATA=read`, the figure scripts and `scripts/73` recompute the plotted values and rewrite `results/figdata/` and
`results/paper_numbers_agg.json`.
